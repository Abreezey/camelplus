# 固定规则的表示变换鲁棒性

日期：2026-10-15。状态：**PARTIAL_OFFLINE**。用户选择的 384 例已完成，完整 D7 未验收。该实验只测 D 的冻结规则检测器，没有 Agent 重规划、工具执行或模型调用。

零宽、逐字空格和 Base64 表示均使本轮条件标签下的攻击检出从 21/24 降至 0/24；全半角表示降至 20/24。大小写、注释包装和本轮中性长前缀不改变原结果。这里验证的是检测输入表示变化后的行为，不能据此声称绕过了完整系统。

## 数据、冻结与边界

运行前冻结 [协议](evidence/D7_representation_protocol.json)、变体源码、原始数据和规则摘要。沿用 D1 已知 24 对样本，每对包含攻击与良性；原文与 7 类变体各 48 例，共 384 条案例观察、416 条来源观察。独立种子仍是 **24 个族**，不能以 n=384 计算独立攻击置信区间。dev/validation/test 保持 12/6/6 族，Test 早已查看，不作盲测或新族泛化声明。

规则为 `d3a-fixed-rules-v1`，阈值 0.75，源码 SHA256 为 `cd852d3881cb70bf60fd98d5d094f797492b3d2af2d0d266af9ded823288b4bd`。每个输入事件都变换，保留原 event/source ID、父关系、继承后的公共标签、来源类别和族归属。各变体单独运行，不做组合搜索或结果驱动修补。

| 表示 | 固定操作 | 实际文本改变的案例 |
|---|---|---:|
| 原文 | 不改变 | 0/48 |
| ASCII 大小写 | 只交换 A–Z/a–z 的大小写 | 35/48 |
| 全半角 | ASCII 可打印字符转全角，普通空格转 U+3000 | 35/48 |
| 零宽 | 每两个原字符之间插入 U+200B | 48/48 |
| 逐字空格 | 每两个原字符之间插入普通空格，保留原有空白 | 48/48 |
| 注释包装 | 用固定 `/* source excerpt` 和 `*/` 包装原文 | 48/48 |
| Base64 包装 | UTF-8 Base64 放入固定 encoded-source 标签 | 48/48 |
| 长前缀 | 原文前置 700 行固定中性背景记录，共 11,200 字符 | 48/48 |

大小写和全半角组有 13 例未改变，分母仍保留全部预列入的 48 例，同时明确记录 changed 状态。长前缀组单源最长 11,269 字符，仍在原检测输入预算内，不能外推为所有长上下文或 LLM 注意力稀释测试。

每个来源都校验能精确还原原文，保留原文/变体文本、两者 SHA256 及还原元数据。全角还原只恢复生成时改动的位置，避免把原本的全角字符错误转回。还原仅用于实验正确性校验；**送入检测器的是变体文本**，raw 与 normalized 使用相同的 identity view，没有实现或替代 B 的规范化、清理、解码。

攻击/良性标签从种子继承，用于成对比较。特别是 Base64，只有消费方能理解对应表示时，才可能保留原攻击意图；本轮没有这样的消费者有效性验证，不把所有编码文本直接称作有效攻击。注释中的攻击种子也不被解释器执行。

所有组均为 0 UNKNOWN。Precision 的分母为 TP+FP，Recall 的分母为全部 24 个攻击种子；无阳性输出时 Precision 未定义，不能写成 100%。

原文 Precision 的 95% 区间为 [59.2%, 89.4%]，全半角为 [60.9%, 91.1%]；完整分子/分母与区间、逐 split、逐来源、逐族计数见原始 summary。每个族只有一对，逐族结果用于定位问题，不能支撑独立性能结论。

零宽和逐字空格切断了连续短语；Base64 中原始短语不再以字面形式出现，规则也没有解码步骤。三组 FP 同时降到 0 是没有检出的伴随结果，不能单独称为效用改善。全半角组变化涉及 `direct04-attack`（原检出转漏报）和 `web01-benign`（原误报转阴性）。原规则在已知其他场景中已有的 3 FN、6 FP 均保留在原文组。

预设 bootstrap 按族连同攻击/良性一起重采样，seed=1729、2000 次，最近秩 2.5/97.5 百分位。差值均为变体减原文，单位为百分点。

| 变体 | 攻击检出差值及 95% 区间 | 良性被标记差值及 95% 区间 |
|---|---|---|
| ASCII 大小写、注释、长前缀（分别计算） | 0 [0, 0] | 0 [0, 0] |

这些区间只反映已知种子集合，没有多重比较校正，不证明新分布的显著性。零差值区间也不表示总体鲁棒性。此次不调整规则或部署选择，不用同批变体修复后再报告为留出成绩。
